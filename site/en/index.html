Have Windows 10? Here's how to switch

Windows 10 no longer gets security updates. Instead of buying a new computer:

  1. Try it without installing: write it to a USB stick and start from it. Type “Will the Wi-Fi work?”, and the system checks Wi-Fi, sound, printer and camera before you change anything.
  2. Back up the folder C:\Users\your-name to an external drive.
  3. Install with disk encryption, in 20–30 minutes.
  4. Move your files: “import my files from windows”. Documents, pictures and the desktop come across, and so do your Chrome and Edge bookmarks. Nothing gets overwritten.
  5. Install what you need: + zoom, + steam, + printer, + install word.

Frequently asked questions

Is it really free?

Yes. Open source under the Apache-2.0 license, with no ads and no subscription.

Does the AI send anything to the internet?

No. The models are downloaded once and checked with SHA-256, and after that they run on your computer. Your questions, files and voice are not sent anywhere.

How do I get updates?

Debian security updates are installed automatically. D.Ai updates come from a signed repository, and only when you choose.

What if something breaks?

Any change you make with a sentence can be undone (dai-tune undo). Ask “why doesn't X work?” (D.Ai Doctor), and report problems on GitHub.
