Sie haben Windows 10? So steigen Sie um

Windows 10 bekommt keine Sicherheitsupdates mehr. Statt einen neuen Computer zu kaufen:

  1. Ohne Installation ausprobieren: auf einen USB-Stick schreiben und davon starten. Tippen Sie „Will the Wi-Fi work?“, und das System prüft WLAN, Ton, Drucker und Kamera, bevor Sie etwas ändern.
  2. Sichern Sie den Ordner C:\Users\Ihr-Name auf eine externe Festplatte.
  3. Installieren mit Festplattenverschlüsselung, in 20–30 Minuten.
  4. Dateien übertragen: „import my files from windows“. Dokumente, Bilder und der Desktop kommen mit, ebenso die Lesezeichen aus Chrome und Edge. Nichts wird überschrieben.
  5. Installieren, was Sie brauchen: + zoom, + steam, + printer, + install word.

Häufige Fragen

Ist es wirklich kostenlos?

Ja. Open Source unter der Lizenz Apache-2.0, ohne Werbung und ohne Abo.

Schickt die KI etwas ins Internet?

Nein. Die Modelle werden einmal heruntergeladen und mit SHA-256 geprüft, danach laufen sie auf Ihrem Computer. Ihre Fragen, Dateien und Ihre Stimme werden nirgendwohin geschickt.

Wie bekomme ich Updates?

Sicherheitsupdates von Debian werden automatisch installiert. Updates von D.Ai kommen aus einer signierten Paketquelle, und nur, wenn Sie es wollen.

Was, wenn etwas kaputtgeht?

Jede Änderung, die Sie mit einem Satz machen, lässt sich rückgängig machen (dai-tune undo). Fragen Sie „why doesn't X work?“ (D.Ai Doctor) und melden Sie Probleme auf GitHub.
