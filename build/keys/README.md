# D.Ai OS archive key

`dai-archive-keyring.asc` (the **public** key that signs D.Ai OS updates) goes here.
The private key lives only in the `DAI_APT_SIGNING_KEY` GitHub secret.
Until the public key exists, images ship without the D.Ai update source.
See [docs/RELEASE.md](../../docs/RELEASE.md) §4.
