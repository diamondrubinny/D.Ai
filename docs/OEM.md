# D.Ai OEM: מחשב מוכן למסירה, והנמען בוחר בעצמו (v0.1)

> מעבדות שיפוץ, עמותות וחנויות מתקינים עשרות מחשבים ([PARTNERS.md](PARTNERS.md)). היום הם מוסרים מחשב עם משתמש וסיסמאות זמניות על מדבקה. ב־Ubuntu יש "OEM install", אבל ב־Calamares של Debian אין. **D.Ai OEM** מכין מחשב מותקן למסירה. באתחול הראשון אצל הנמען נפתח אשף קצר שבו הוא בוחר שם, משתמש, סיסמה, שם מחשב **וסיסמת הצפנה חדשה**. המשתמש הזמני של השותף נמחק.

## 1. הזרימה

| # | מי | מה |
|---|----|----|
| 1 | השותף | מתקין כרגיל (Calamares) עם הצפנה, משתמש זמני (למשל `oem`) וסיסמת הצפנה זמנית. מעדכן ומתקין מה שצריך |
| 2 | השותף | `sudo dai-oem prepare`: בודק את סיסמת ההצפנה הזמנית, מכין את האשף ומנקה. בסוף מכבה (`--poweroff`) |
| 3 | הנמען | מדליק ומזין את סיסמת ההצפנה הזמנית (מהמדבקה). זו הפעם היחידה שהוא צריך אותה |
| 4 | הנמען | ‏**האשף** (מסך מלא, בלי פאנל): שפה → שם, משתמש וסיסמה → שם מחשב → סיסמת הצפנה חדשה → סיכום → "סיום" |
| 5 | המערכת | יוצרת את המשתמש (מנהל), מחליפה את סיסמת ההצפנה, מבטלת את האשף ומאתחלת |
| 6 | המערכת | באתחול הבא, **לפני מסך הכניסה**: מוחקת את המשתמש הזמני ואת משתמש האשף, ומייצרת מפתחות SSH חדשים (אם יש) |
| 7 | הנמען | נכנס עם המשתמש שלו. ‏**D.Ai Welcome** נפתח כרגיל |

## 2. מה `dai-oem prepare` עושה

1. בודק: root, מערכת מותקנת (לא live), ומשתמש זמני אמיתי (‏UID ≥ 1000, ‏`$SUDO_USER` או `--remove-user`).
2. אם השורש מוצפן (LUKS ב־`/etc/crypttab`): מבקש את סיסמת ההצפנה הזמנית, **בודק אותה** (`cryptsetup open --test-passphrase`) ושומר אותה ב־`/var/lib/dai/oem/luks-key` ‏(root, ‏0600, בתוך הדיסק המוצפן). היא נמחקת (shred) כשהנמען מחליף אותה.
3. יוצר משתמש מערכת `dai-setup` (סיסמה נעולה, בלי sudo) ומגדיר ל־SDDM כניסה אוטומטית שלו לסשן `dai-oem` ‏(labwc עם האשף בלבד, בלי פאנל וקיצורים).
4. מנקה: ‏`apt-get clean`, יומני systemd, ‏`/etc/machine-id` ריק (כל מחשב יקבל מזהה משלו), ומפתחות SSH של המחשב.
5. כותב `/var/lib/dai/oem/state.json`: ‏`pending`, ומי המשתמש הזמני.

## 3. אבטחה

| איום | בקרה |
|------|------|
| מישהו אחר מפעיל את "סיום ההגדרה" כ־root | ‏polkit: הפעולה מותרת **בלי סיסמה** רק למשתמש `dai-setup`, בסשן מקומי ופעיל. לכל אחד אחר: סיסמת מנהל. ה־helper גם בודק בעצמו ש־`PKEXEC_UID` הוא `dai-setup` ושהמצב `pending` |
| קלט זדוני מהאשף | ה־helper מאמת הכל מחדש: שם משתמש `^[a-z][a-z0-9-]{0,31}$` ולא קיים/שמור, שם מלא בלי `:`, `,` ושורות חדשות, סיסמה 8–256 תווים, hostname לפי RFC 1123. פקודות רצות בלי shell |
| סיסמאות ב־argv או ביומן | סיסמאות עוברות רק ב־stdin (`chpasswd`, ‏`cryptsetup`). שום סיסמה לא נכתבת ללוג |
| סיסמת ההצפנה הזמנית נשארת | נשמרת רק עד ההחלפה, בתוך הדיסק המוצפן, 0600, ונמחקת ב־shred. אם ההחלפה נכשלת, האשף מראה שגיאה ולא ממשיך |
| ההחלפה נכשלת באמצע | ‏`luksChangeKey` מחליף slot בצורה אטומית ב־cryptsetup. אם הוא נכשל, הסיסמה הישנה עדיין עובדת והמשתמש לא נוצר. הסדר: קודם הצפנה, אחר כך משתמש |
| משתמש `dai-setup` נשאר | נמחק באתחול הבא (`dai-oem-cleanup.service`), יחד עם המשתמש הזמני והתיקיות שלהם |
| השותף שוכח מידע אישי | ‏PARTNERS.md §2: מחיקה מאובטחת **לפני** ההתקנה. ‏OEM לא מחליף אותה |

## 4. מגבלות (v0.1)

- סיסמת ההצפנה הזמנית עדיין נדרשת פעם אחת, באתחול הראשון (initramfs שואל לפני שהמערכת עולה). שינוי לזה דורש TPM או מפתח זמני ב־initramfs, וזה לא חלק מ־v0.1.
- רק שורש מוצפן אחד (שורה אחת של LUKS ב־crypttab) מוחלף. מחשבים עם כמה דיסקים מוצפנים: ידנית.
- ‏`dai-oem prepare` לא מוחק נתונים של בעלים קודמים. זה שלב 2 בנוהל של PARTNERS.md.

## 5. בדיקות

- יחידה: אימות קלט (שמות, סיסמאות, hostname), תוכנית הפקודות של prepare/complete/cleanup עם runner מזויף ושורש זמני, ‏polkit rule, ‏הגנה מפני PKEXEC_UID אחר ומצב לא pending, ‏GUI (מעברים, אימות, RTL).
- ‏**cryptsetup אמיתי** (CI, כ־root): כותרת LUKS2 בקובץ image. ‏prepare דוחה סיסמה זמנית שגויה, ‏complete מחליף לסיסמה חדשה בעברית, הסיסמה החדשה נפתחת כמו בהפעלה (עד סוף השורה), הישנה נדחית, ולא נשאר קובץ מפתח.
- ‏**VM** ‏(CI, בסשן ה־live עם `--allow-live`): ‏prepare עם משתמש זמני שנוצר לבדיקה → ה־helper עם JSON → המשתמש החדש קיים בקבוצות sudo ו־lpadmin ועם hash של yescrypt ב־`/etc/shadow`, ‏hostname, ‏SDDM חזר למצבו → ‏cleanup → המשתמש הזמני ו־dai-setup נמחקו. ‏LUKS לא נבדק ב־VM כי אין דיסק מותקן.
- ‏**labwc אמיתי** (מקומי): סשן ה־OEM נטען בלי שגיאות, והאשף נפתח במסך מלא ב־Wayland.
