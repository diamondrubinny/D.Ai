# ערכה לשותפים: מעבדות שיפוץ מחשבים, עמותות וארגונים

> חומרה שמגיעה עם המערכת מותקנת היא מה שהזיז את SteamOS, ‏Ubuntu ו־ChromeOS ([GROWTH.md](GROWTH.md)). בישראל יש מאות אלפי מחשבים שלא יכולים לעבור ל־Windows 11. שותף שמתקין D.Ai OS נותן להם חיים חדשים, בלי עלות רישוי.

## 1. דף אחד לשותף (לשליחה)

**‏D.Ai OS: חיים חדשים למחשב שלא יכול לקבל Windows 11**

- **חינם, קוד פתוח (Apache-2.0)**, מבוססת Debian. אין עלות רישוי למחשב, ואין מנוי.
- **בעברית מהיסוד:** ממשק מימין לשמאל, הכתבה קולית בעברית, ‏LibreOffice בעברית.
- **מאובטחת ופרטית:** הצפנת דיסק, חומת אש, עדכוני אבטחה אוטומטיים, ובלי טלמטריה ופרסומות. ה־AI רץ במחשב.
- **פשוטה לתמיכה:** המשתמש שואל "למה המחשב איטי?" ו"למה המדפסת לא עובדת?" ‏(D.Ai Doctor), ומגדיר במשפט. כל שינוי אפשר לבטל.
- **מהדורת חינוך** עם אפליקציות למידה, וניהול מרוכז של צי מחשבים ([EDU.md](EDU.md)).
- **דרישות:** ‏x86_64, ‏4GB זיכרון (8GB ומעלה ל־AI), ‏25GB דיסק.

## 2. נוהל הכנת מחשב למסירה

| # | שלב | איך |
|---|-----|-----|
| 1 | **בדיקת חומרה** לפני התקנה | מאתחלים מה־USB ‏(live) ומריצים `dai-doctor hardware`: ‏Wi-Fi, רשת, גרפיקה, קול, מצלמה ומדפסת. רכיב "אין דרייבר" → מתעדים, או מחליפים כרטיס |
| 2 | **מחיקה מאובטחת** של נתוני הבעלים הקודמים | "מחיקת דיסק" במתקין **לא** מוחקת נתונים ישנים בצורה מאובטחת. מתוך ה־live: ב־SSD/NVMe ‏`sudo blkdiscard -f /dev/<disk>` (או `nvme format --ses=1`), ובדיסק מכני `sudo shred -n1 -z /dev/<disk>`. **בודקים פעמיים את שם הדיסק** |
| 3 | **התקנה** | "התקנת D.Ai OS", מחיקת הדיסק, **הצפנת מערכת** עם סיסמה זמנית (נרשמת במדבקה). משתמש: `user`, עם סיסמה זמנית |
| 4 | **עדכון** | אחרי האתחול הראשון: `sudo apt update && sudo apt full-upgrade` |
| 5 | **הכנה למסירה** | `sudo passwd --expire user`: המשתמש יתבקש לבחור סיסמה חדשה בכניסה הראשונה. ‏**D.Ai Welcome** ייפתח מעצמו ויציע רמת אבטחה ומודלים מקומיים |
| 6 | **מסירה** | מצרפים את דף המסירה (סעיף 3) עם הסיסמאות הזמניות |

> ‏OEM mode מלא, שבו הנמען בוחר בעצמו שם משתמש והצפנה באתחול הראשון, **מתוכנן**. ‏Calamares לא תומך בזה כמו שהוא.

## 3. דף מסירה לנמען

1. מדליקים. מזינים את **סיסמת ההצפנה הזמנית** שעל המדבקה.
2. נכנסים עם המשתמש `user` והסיסמה הזמנית, ובוחרים **סיסמה חדשה**.
3. ‏**מחליפים את סיסמת ההצפנה:** בטרמינל `sudo cryptsetup luksChangeKey /dev/<partition>`. ‏`lsblk -f` מראה את המחיצה מסוג `crypto_LUKS`. מזינים את הישנה ואז את החדשה. **אם שוכחים אותה, אי אפשר לפתוח את המחשב.**
4. מוציאים את המדבקה עם הסיסמאות הזמניות ומשמידים אותה.
5. ‏**ברוכים הבאים** נפתח לבד. ממשיכים משם. עזרה: ‏`Super+Space` ושואלים.

## 4. מה השותף מקבל

- ‏ISO חתום (`SHA256SUMS`) מ־GitHub Releases, וערוץ דיווח תקלות.
- רשימת חומרה שנבדקה (תתעדכן לפי דיווחים).
- אפשרות להכין **קובץ מדיניות** לארגון ([EDU.md](EDU.md) §2).

## 5. נושאים לבדיקה מקצועית לפני שותפות

- ‏**משפטי:** אחריות על מחשב משופץ, תנאי שימוש, שימוש בשם ובלוגו של D.Ai על ידי השותף.
- ‏**פרטיות:** תהליך המחיקה המאובטחת מול חוק הגנת הפרטיות ותקנות אבטחת מידע. תיעוד שהמחיקה בוצעה.
- ‏**רישוי:** תוכנות צד שלישי (Flathub) שהשותף מתקין מראש כפופות לרישיונות שלהן.
