# D.Ai OS — מערכת עיצוב וחוויית משתמש (v0.1)

> מסמך עבודה. כל צבע וניגודיות נבדקו מול WCAG 2.1 AA. ⚠️ = דורש אימות ידני על חומרה אמיתית.

## 1. עקרונות

1. **מהיר וקל** — בלי אנימציות כבדות, בלי שירותי רקע מיותרים. כל רכיב חייב להצדיק את ה־RAM שלו.
2. **הכל במקום אחד** — שורת המשימות היא מרכז השליטה: "התחל", שורת פקודות, חלונות, מגש, שפה, שעון.
3. **עברית מהיום הראשון** — RTL מלא, החלפת שפה ב־Alt+Shift, ותיקון טקסט שהוקלד בשפה הלא נכונה.
4. **פרטיות כברירת מחדל** — אין פרסומות, אין טלמטריה, אין עדכונים שמאלצים הפעלה מחדש.
5. **נגישות היא לא תוסף** — ניגודיות AA, ניווט מקלדת מלא, קורא מסך בקיצור אחד.

## 3. שורת המשימות

```
┌─────────┬──────────────────────────┬──────────────────────────────┬────┬────┬──────┬────────┬───┐
│ ◆ התחל  │ ⌘  הקלד פקודה…   Super+␣ │  [חלון] [חלון] [חלון]  …     │מגש │ HE │ 🔊   │ 14:05  │ ▭ │
└─────────┴──────────────────────────┴──────────────────────────────┴────┴────┴──────┴────────┴───┘
```

- תחתונה, גובה 44px, רקע "זכוכית" כהה (`bg-900` ב־92% אטימות) עם פס גרדיאנט דק מלמעלה.
- **התחל**: תפריט LXQt (`fancymenu`) עם חיפוש, מועדפים וקטגוריות.
- **שורת פקודות**: כפתור שנראה כמו שדה חיפוש, ליד "התחל". לחיצה עליו או `Super+Space` פותחים את **D.Ai Command** (§4).
- **שפה**: אינדיקטור `HE`/`EN`, ולחיצה עליו מחליפה שפה.
- בעברית (`LANG=he_IL`) כל הפאנל מתהפך אוטומטית (Qt RTL).

## 4. D.Ai Command — שורת פקודות אחת לכל דבר

חלון פקודות במרכז המסך, בסגנון Spotlight/PowerToys Run. מה שאין למתחרים: עברית ו־AI מקומי.

| הקלדה | תוצאה |
|-------|-------|
| שם אפליקציה (גם בעברית: "דפדפן") | פתיחת האפליקציה |
| `2*(3+4)` / `15% of 80` | מחשבון. Enter מעתיק את התוצאה |
| `akuo` | **תיקון שפה**: "שלום". Enter מעתיק |
| `>` + פקודה | הרצה בטרמינל |
| `$` + פקודה | הרצה ברקע |
| `?` + שאלה | שאלה ל־AI המקומי (שלב 3, כרגע מוצגת הודעה) |
| 🎤 | הכתבה קולית (שלב 5) |

- `Esc` סוגר, `↑↓` מנווטים, `Enter` מפעיל.
- היסטוריה מקומית בלבד, בהרשאות 0600. פקודה שמתחילה ברווח לא נשמרת (כמו `HISTCONTROL=ignorespace`).
- אין `eval` למחשבון. החישוב עובר דרך מפרש AST עם whitelist.

## 7. נגישות — בדיקות לכל רכיב חדש

- ניווט מקלדת בלבד, פוקוס גלוי.
- שמות נגישים (`accessibleName`) לכל כפתור ושדה.
- ניגודיות AA (§2).
- זום 200%, RTL, ובדיקה עם Orca ⚠️ (ידני).
