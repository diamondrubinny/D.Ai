# D.Ai Doctor: "למה המחשב איטי?" ו"מה תופס לי את הדיסק?" (v0.1)

> אלה השאלות הנפוצות ביותר באתרי תמיכה ([RESEARCH.md](RESEARCH.md) §1, כאב 5). Doctor עונה בשפה פשוטה ומציע תיקון בטוח. הוא לא משנה כלום בלי אישור.

## 1. שימוש

| איפה | איך |
|------|-----|
| ‏D.Ai Command | שואלים: "למה המחשב איטי?", ‏"מה תופס את הדיסק?", ‏"כמה סוללה נשארה?", ‏"why is my computer slow". הממצאים העיקריים מופיעים בשורה עצמה, ו־Enter פותח את האבחון המלא עם התיקונים |
| טרמינל | `dai-doctor` (הכל), ‏`dai-doctor slow`, ‏`disk`, ‏`battery`, ‏`--json` |

## 2. מה נבדק

| נושא | בדיקה | ממצא ותיקון |
|------|-------|-------------|
| איטיות | זיכרון פנוי (`/proc/meminfo`) | פחות מ־20% → מי משתמש הכי הרבה; עצה: לסגור |
| | swap | שימוש כבד כשהזיכרון כמעט מלא → אזהרה |
| | עומס מעבד ותהליכים (דגימה של חצי שנייה ב־`/proc`) | התהליכים העמוסים. רכיבי שולחן העבודה עצמו לא "מואשמים" לעולם |
| | שירותים שנכשלו (`systemctl --failed`) | שמות, ואיך רואים פרטים |
| | זמן מאז הפעלה | 14 ימים ומעלה → הפעלה מחדש מחילה עדכונים |
| דיסק | מקום פנוי ב־`/` ובבית | אזהרה מתחת ל־5GB או 8%; קריטי מתחת ל־2GB או 3% |
| | ‏cache של המערכת (חבילות שהורדו, יומנים) | **‏D.Ai Tune**: ‏"free up disk space" (‏`system.clean`) |
| | סל המחזור ותצוגות מקדימות | ניקוי אחרי אישור: רק `~/.local/share/Trash` ו־`~/.cache/thumbnails` |
| | התיקיות הגדולות בבית | רשימה, בלי לשנות דבר |
| סוללה | בריאות (`energy_full` מול `energy_full_design`), טעינה, מצב | שחוקה (פחות מ־70%) → עצה; פחות מ־30% → **‏D.Ai Tune**: ‏"battery saver mode" (‏`power.profile`) |

## 3. בטיחות

- **קריאה בלבד** מ־`/proc`, ‏`/sys` ומהדיסק. אין צורך בהרשאות root לאבחון.
- **שינויי מערכת** עוברים כמשפט ל־D.Ai Tune, עם תוכנית, ‏polkit, יומן ו־`dai-tune undo` (חוץ מניקוי cache, שאי אפשר להחזיר).
- **ניקוי משתמש** נוגע רק בשתי התיקיות האלה. קישורים סימבוליים נמחקים כקישור ולא עוקבים אחריהם, ותיקייה שהיא קישור לא נוגעים בה.
- תהליכים **לא נסגרים** אוטומטית. Doctor רק מראה מי עמוס.

## 4. סוללה

ב־D.Ai OS מותקן `power-profiles-daemon`, עם שלושה מצבים: חיסכון, מאוזן וביצועים. מחליפים מצב במשפט ("מצב חיסכון בסוללה"), ו־`dai-tune undo` מחזיר למצב הקודם.
