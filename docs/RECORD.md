# D.Ai Record: "הקלט את המסך" (שלב 1)

> נכתב ב־2026-10-31 אחרי "המשך בפיתוח פיצרים". צילום מסך כבר יש (Print); זו ההקלטה: סרטון של המסך, במשפט או
> בקיצור, עם סוף ברור, הודעה וצליל, ובלי שום דבר שעוזב את המחשב.

## 1. הרעיון

"record my screen for 30 seconds", "record the screen", "stop recording" / "הקלט את המסך 30 שניות", "הקלטת מסך",
"עצור הקלטה" בשורת הפקודה; או **Super+Shift+R** (התחלה; לחיצה שנייה עוצרת). הסרטון נשמר ב־`~/Videos/Recordings/`
(‏`Recording-YYYY-MM-DD-HHMMSS.mp4`), הודעה בהתחלה ("מקליט… Super+Shift+R עוצר") ובסוף (הקובץ), צליל
`screen-capture` מהמשפחה של היהלום. בלי משך: עד שעוצרים.

## 2. איך זה עובד

- **wf-recorder** (Debian 13, ‏0.5.0; ‏wlr-screencopy, אותו פרוטוקול כמו grim) עם `-f FILE`; `--area` בוחר אזור עם slurp.
  בלי שמע כברירת מחדל (מיקרופון/רמקולים הם החלטה נפרדת; מחוון הפרטיות מראה מיקרופון בכל מקרה).
- **pid**: `$XDG_RUNTIME_DIR/dai/record.pid` (0600); כמו ב־Speak, לפני עצירה נבדק ש־`/proc/PID/comm` הוא `wf-recorder`.
  עצירה = SIGINT (wf-recorder סוגר את הקובץ כמו שצריך).
- **משך**: `dai-record start 30` מפעיל גם שומר קטן (`dai-record _wait PID 30`, תהליך מנותק) ששולח SIGINT בזמן
  ומודיע על הקובץ. ‏`dai-record toggle` = התחלה בלי משך או עצירה (הקיצור).
- **Command**: `RECORD_WORDS` → שורה "הקלטת המסך (30 שניות)" (`kind="record"`), "stop recording" → עצירה. ‏labwc: `W-S-r`.

## 3. פרטיות ואבטחה

- הקובץ נשאר במחשב; שום דבר לא נשלח. ההודעה מכילה את נתיב הקובץ בלבד.
- `dai-record` לא מריץ shell; הנתיב והמשך הם ארגומנטים; המשך 1–3600 שניות.
- הקלטה רצה כמשתמש, ונעצרת גם כשהחלון של D.Ai נסגר (התהליך מנותק).

## 4. בדיקות

יחידה: argv (קובץ, אזור, בלי שמע), התחלה/עצירה עם pid מאומת, המשך דרך השומר, ה־CLI, Command (מילים, שורות).
‏VM: `record: three seconds of the screen` (‏`dai-record start 3 --file /tmp/rec.mp4` תחת Wayland, אחרי ~8 שניות קובץ
לא ריק ו־`.pid` נעלם).
