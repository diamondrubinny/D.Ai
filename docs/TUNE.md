# D.Ai Tune — התאמת מערכת ההפעלה בטקסט, באבטחה מלאה (v0.1)

> "תכתוב מה אתה צריך — המערכת תבנה את עצמה." בלי לחפש בהגדרות, בלי פקודות טרמינל, ובלי להתפשר על אבטחה.

## 1. מה זה

D.Ai Tune מקבל משפט בעברית או באנגלית, ומחזיר **תוכנית שינויים** שאפשר לבדוק לפני שמאשרים:

```
$ dai-tune "חסום דיסק און קי, כבה בלוטות' ונעל מסך אחרי 5 דקות"

D.Ai Tune — תוכנית שינויים  #3f9a1c
  1. 🛡  חסימת התקני אחסון USB             מערכת · סיכון נמוך · מחזק אבטחה
  2. 🛡  כיבוי Bluetooth                   מערכת · סיכון נמוך · מחזק אבטחה
  3. 🛡  נעילת מסך אחרי 5 דקות             משתמש · סיכון נמוך · מחזק אבטחה
  קבצים: /etc/modprobe.d/dai-tune-usb_storage.conf, ...
  להחלה? [כ/ל]
```

אחרי ההחלה: `dai-tune undo` מחזיר הכל למצב הקודם, ו־`dai-tune status` מציג **ציון אבטחה** עם המלצות. כל המלצה היא משפט שאפשר פשוט להקליד.

## 2. מה ייחודי

| | Windows / macOS / Ubuntu | D.Ai Tune |
|-|--------------------------|-----------|
| שינוי הגדרות | עשרות מסכים | משפט אחד, בעברית |
| שקיפות | שינויים נסתרים | תוכנית מלאה לפני ביצוע: מה, איפה, סיכון |
| ביטול | בדרך כלל אין | `undo` לכל שינוי, מיומן |
| אבטחה | המשתמש צריך לדעת מה לעשות | ציון אבטחה + "תגיד כדי לתקן" |
| שחזור | — | ייצוא כל ההתאמות לקובץ אחד והחלה במחשב אחר (שלב 2) |
| AI | עוזר בענן שמריץ פקודות | AI מקומי שיכול **רק להציע** פעולות מהקטלוג (שלב 3) |

## 3. ארכיטקטורה

```
 טקסט (עברית/אנגלית)                    ← D.Ai Command ("!…") / dai-tune CLI
        │
   parser.py   ── כללים דטרמיניסטיים, offline (ובשלב 3 גם LLM מקומי → אותו פורמט)
        │  ActionRequest(id, params)
   planner.py  ── ולידציה מול הקטלוג, תלויות (ssh → פורט 22 ברשת מקומית), סיכון, hash
        │  Plan (JSON)
   CLI: הצגת תוכנית → אישור (פעולה מחלישה = הקלדת "כן" מלאה; ‎--yes אסור)
        │
   ┌────┴─────────────────────────┐
 צעדי משתמש                       צעדי מערכת
 executor.py (בתהליך המשתמש)       pkexec → dai-tune-helper (root)
                                   │  * ולידציה מחדש של כל צעד (לא סומך על ה־CLI)
                                   │  * דוחה צעדים שאינם בקטלוג / scope=user
                                   │  * snapshot → apply → rollback בכשל
 journal (‎~/.local/state)          journal ‏(/var/lib/dai/tune, 0700)
```

## 4. מודל האבטחה

1. **אין shell.** פעולות מריצות רק `argv` קבועים, כמו `systemctl` ו־`nft` עם ארגומנטים מאומתים, ובלי `shell=True`. שמות חבילות, פורטים, שמות מחשב ואזורי זמן עוברים regex או whitelist.
2. **קטלוג סגור.** כל יכולת היא פעולה מוגדרת, עם `scope` (משתמש/מערכת), רמת סיכון והשפעה על האבטחה (מחזק/מחליש/ניטרלי).
3. **הפרדת הרשאות.** הממשק רץ כמשתמש רגיל. רק `dai-tune-helper` רץ כ־root, דרך polkit (`auth_admin_keep`), והוא מאמת מחדש כל צעד.
4. **ברירות מחדל בטוחות.** "פתח פורט 8080" פותח **רק לרשת המקומית**. "מכל מקום" חייב להיאמר במפורש, ומסומן כסיכון גבוה.
5. **פעולה מחלישה דורשת הסכמה מפורשת:** הקלדת "כן" או "yes". הדגל ‎`--yes` נדחה עבורה.
6. **אימות לפני החלה.** חוקי Firewall נבדקים ב־`nft -c` לפני טעינה, וטעינה כושלת מחזירה את הקובץ הקודם.
7. **טרנזקציה.** כשל בצעד N מבטל את צעדים 1..N-1 אוטומטית.
8. **יומן ביקורת.** מי (UID דרך `PKEXEC_UID`), מתי, מה, ה־hash והתוצאה. היומן לא שומר סודות.
9. **הגנות.** חבילות קריטיות (`systemd`, `sudo`, `nftables`, `apparmor`, `linux-image-*`, רכיבי D.Ai) לא ניתנות להסרה. מספר הצעדים בתוכנית מוגבל.

### Threat model מקוצר

| איום | בקרה |
|------|------|
| הזרקת פקודה דרך טקסט (`התקן vlc; rm -rf /`) | regex לשמות חבילות, argv בלבד, נבדק בבדיקות יחידה |
| אפליקציה זדונית מפעילה את ה־helper | polkit דורש סיסמת מנהל; ה־helper מאמת מחדש |
| AI (בעתיד) "ממציא" פעולה מסוכנת | ה־AI מחזיר JSON שעובר אותו validator; מה שלא בקטלוג נדחה |
| משתמש פותח פורט לכל העולם בטעות | ברירת מחדל רשת מקומית; "מכל מקום" = סיכון גבוה + "כן" |
| שינוי שובר את המערכת | snapshot ו־undo; בדיקת `nft -c`; rollback אוטומטי |
| מתקפה על קבצי היומן | ‏`/var/lib/dai/tune` 0700 root; יומן המשתמש 0600 |

## 5b. מדיניות ארגונית (`/etc/dai/policy.d`)

קבצי JSON בבעלות root עם משפטים של Tune, שמוחלים בכל אתחול ובכל שינוי בתיקייה (`dai-policy.path`). רק פעולות מערכת מותרות. `dai-tune policy` מציג מה פעיל ומה נדחה. פרטים: [EDU.md](EDU.md).

## 6. ציון אבטחה (`dai-tune status`)

| בדיקה | משקל |
|-------|------|
| Firewall חוסם נכנס | 20 |
| אין פורטים פתוחים לכל העולם | 15 |
| עדכוני אבטחה אוטומטיים | 15 |
| AppArmor פעיל | 15 |
| הצפנת דיסק (dm-crypt) | 15 |
| נעילת מסך ≤ 10 דקות | 10 |
| SSH כבוי או מוגבל לרשת מקומית | 10 |

לכל בדיקה שנכשלת מוצג משפט מוכן, למשל: `dai-tune "הפעל עדכונים אוטומטיים"`.

## 7. ממשקים

- `dai-tune "<טקסט>"`: תוכנית, אישור והחלה. אפשרויות: ‎`--dry-run`, ‎`--json`, ‎`--yes` (רק לפעולות לא מחלישות).
- `dai-tune undo [id|last]`, `dai-tune history`, `dai-tune status`, `dai-tune help` (מה אפשר לבקש).
- **D.Ai Command:** הקלדת `!` ואחריו טקסט מציגה את התוכנית בשורות, ו־Enter פותח את dai-tune לאישור.
