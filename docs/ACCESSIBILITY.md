# הצהרת נגישות: D.Ai OS (טיוטה)

> **טיוטה.** דורשת בדיקה של מורשה נגישות / יועץ נגישות לפני פרסום. אין בה הצהרה על עמידה מלאה בתקן ת"י 5568 או ב־WCAG.

## מחויבות

‏D.Ai OS מתוכננת כך שאנשים עם מוגבלות יוכלו להשתמש בה בלי עזרה. היעד הוא WCAG 2.1 ברמה AA בכלים שלנו, בהתאם לת"י 5568.

## מה קיים היום

| תחום | מה יש | איפה |
|------|-------|------|
| קורא מסך | ‏Orca, הפעלה ב־`Super+Alt+S` | המערכת כולה |
| מקלדת | כל כלי D.Ai (Command, ‏Forge, ‏Welcome, ‏Doctor, ‏Backup) עובדים במקלדת בלבד. ‏Esc סוגר, ו־Tab מסומן במסגרת בולטת | נבדק בבדיקות יחידה (Welcome, ‏Forge) |
| כיוון | עברית מימין לשמאל, כולל שורות מעורבות בעברית ובאנגלית | D.Ai Welcome, ‏Command, ‏Forge |
| ניגודיות | ערכת D.Ai Night בניגודיות AA. בדיקה מחושבת קיימת לאתר | [DESIGN.md](DESIGN.md), ‏`tests/site` |
| שמות נגישים | לכפתורים, לתיבות ולשדות בכלי D.Ai יש שם ותיאור נגישים | נבדק ב־Welcome |
| קול | הכתבה בעברית ובאנגלית (`Super+H`), ופקודות קוליות | [VOICE.md](VOICE.md) |
| תנועה | אין אנימציות חובה. האתר מכבד את prefers-reduced-motion | |
| פשטות | הגדרות במשפט ("נעל מסך אחרי 5 דקות") במקום ניווט במסכים | [TUNE.md](TUNE.md) |

## מגבלות ידועות

- טרם נבדק עם משתמשים עם מוגבלות ובבדיקת מומחה.
- אפליקציות צד שלישי (דפדפן, ‏LibreOffice, אפליקציות Flathub) נגישות לפי מה שהיצרנים שלהן מספקים.
- מתג "ניגודיות גבוהה" ו"טקסט גדול" במשפט אחד: מתוכנן כפעולות Tune.
- אפליקציות ש־Forge בונה רצות בארגז חול. הנגישות שלהן בתוך הארגז (AT-SPI) **דורשת בדיקה**.
