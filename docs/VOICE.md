# D.Ai Voice: דיבור במקום הקלדה, מקומי לגמרי (v0.1)

> מדברים בעברית או באנגלית והמחשב כותב או מבצע, בלי ענן ובלי חשבון. ההקלטה לא נשמרת ולא יוצאת מהמחשב.

## 1. מה זה

| קיצור / כפתור | מה קורה |
|---------------|---------|
| `Super+H` | **הכתבה בכל אפליקציה**: לחיצה ראשונה מתחילה להקליט, לחיצה שנייה עוצרת. הטקסט מוקלד בחלון הפעיל |
| `Super+Shift+Space` | **פקודה קולית**: הטקסט נפתח ב־D.Ai Command. למשל "פתח את פיירפוקס", "?מה זה DNS", "+תתקין אנטי וירוס" |
| 🎙 ב־D.Ai Command ובחלון Forge | לחיצה מקליטה, לחיצה נוספת ממלאת את שדה הבקשה |
| `dai-voice transcribe קובץ.wav` | תמלול קובץ מהטרמינל |

## 2. ארכיטקטורה

```
מיקרופון ─► pw-record (PipeWire, 16kHz mono) ─► $XDG_RUNTIME_DIR/dai/voice.wav   (tmpfs, תיקייה 0700)
                                                     │  (מוגבל ל־120 שניות)
                                                     ▼
          bubblewrap: ללא רשת, ללא בית, /usr ו־/opt/dai/whisper לקריאה בלבד
                    whisper-cli (whisper.cpp v1.9.5 מוצמד ל־commit)  ─►  טקסט
                                                     │
                       הקובץ נמחק מיד ───────────────┤
                                                     ▼
                    wtype (הקלדה בחלון הפעיל) / dai-command --query / stdout
```

- **whisper.cpp** נבנה ב־CI מגרסה מוצמדת (tag ו־commit), בלי curl, SDL או ffmpeg. גרסת ה־CPU המתאימה למעבד (SSE4.2…AVX‑512) נבחרת בזמן ריצה.
- **מודלים** (`dai-models`, אותו מנגנון של מודלי השפה: HTTPS ו־SHA‑256 מוצמד):

| מזהה | גודל | מתאים ל |
|------|------|---------|
| `whisper-base` | כ־150MB | מהיר, טוב לאנגלית ובסיסי לעברית |
| `whisper-small` | כ־470MB | **מומלץ לעברית** |
| `whisper-large-v3-turbo` | כ־550MB (Q5) | הדיוק הגבוה ביותר, איטי יותר במעבד |

## 3. פרטיות ואבטחה

| איום | בקרה |
|------|------|
| הקלטה סמויה | הקלטה מתחילה רק בפעולה מפורשת של המשתמש. כל זמן ההקלטה מוצגת התראה "🎙 מקליט". ההקלטה נעצרת אוטומטית אחרי 120 שניות |
| דליפת הקלטה | הקובץ נשמר רק ב־tmpfs של המשתמש (`$XDG_RUNTIME_DIR/dai`, 0700) ונמחק מיד אחרי התמלול. הטקסט לא נשמר |
| דליפה לרשת | whisper.cpp נבנה בלי קוד רשת, ובנוסף רץ ב־bubblewrap עם `--unshare-all` (בלי רשת) |
| קובץ אודיו או מודל זדוני שמנצל באג בפענוח | ארגז חול: בלי גישה לבית, `cap-drop ALL`, קבצי מערכת לקריאה בלבד |
| מודל מזויף | HTTPS ו־SHA‑256 מוצמד, כמו מודלי השפה |
| פקודה קולית שמבצעת פעולה מסוכנת | הקול רק ממלא טקסט. ב־D.Ai Command, ב־Tune וב־Forge כל פעולה מוצגת ודורשת אישור כרגיל |

## 4. הגדרות

`~/.config/dai/voice.json`: ‏`{"lang": "auto" | "he" | "en", "model": "whisper-small"}`. ברירת המחדל: זיהוי שפה אוטומטי והמודל הקטן ביותר שמותקן.

## 5. מגבלות ידועות

- ההקלדה בחלון הפעיל משתמשת ב־`wtype` (פרוטוקול virtual-keyboard של Wayland). אפליקציות X11 שרצות ב־Xwayland מקבלות את ההקלדה, אבל זה תלוי ב־labwc. דורש בדיקה על חומרה.
- התמלול מתבצע אחרי סיום ההקלטה ולא בזמן אמת (streaming), ומשכו תלוי במעבד.
- זיהוי "מילת הפעלה" (wake word) לא קיים, ולא ייבנה כברירת מחדל: הוא דורש מיקרופון פתוח כל הזמן.
