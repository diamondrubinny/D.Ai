# עוברים מ־Windows 10 ל־D.Ai OS: מדריך צעד אחר צעד

> ‏Windows 10 לא מקבל עדכוני אבטחה מאז 14.10.2025 (אפשר לשלם על עדכונים מורחבים עד 2028). הרבה מחשבים טובים לא עומדים בדרישות של Windows 11. ‏D.Ai OS נותנת להם חיים חדשים: מהירה, מאובטחת, בעברית ובלי פרסומות. המדריך כנה גם לגבי מה שלא יעבוד.

## לפני שמתחילים: האם זה מתאים לכם?

| עובד מצוין | עובד, עם הבדל | **לא יעבוד** |
|------------|---------------|--------------|
| גלישה (Firefox, ואפשר Chrome), דואר, ‏WhatsApp Web, ‏Zoom, ‏Spotify, ‏Discord, ‏Telegram | ‏Word, ‏Excel ו־PowerPoint: ‏LibreOffice מובנה, ו־ONLYOFFICE לתאימות גבוהה יותר (`+ install word`) | **משחקים עם anti-cheat בליבה** (Call of Duty, ‏Valorant, ‏Battlefield 6 ועוד) |
| רוב משחקי Steam (דרך Proton) | תוכנות Windows קטנות דרך Bottles (`+ תוכנות ווינדוס`). לא הכל עובד | ‏**Adobe** (Photoshop, ‏Premiere) ‏— יש חלופות (GIMP, ‏Krita, ‏Kdenlive), אבל הן לא אותו דבר |
| הדפסה וסריקה ברוב המדפסות (`+ מדפסת`) | ‏VPN של העבודה: ‏OpenVPN, ‏Cisco, ‏GlobalProtect, ‏Fortinet (`+ vpn של העבודה`) | תוכנות מקצועיות ל־Windows בלבד (חלק מ־CAD, תוכנות הנהלת חשבונות ישראליות שמותקנות מקומית) |
| ‏AI, הכתבה קולית וחיפוש קבצים, הכל במחשב | | ‏**כרטיס חכם / חתימה דיגיטלית** של גופים מסוימים: **דורש בדיקה** מול הספק |

> אם משהו בעמודה השמאלית חיוני לכם, אפשר להשאיר את Windows במחשב (dual boot, ‏**לא מומלץ באלפא**) או במחשב אחר.

## שלב 1: נסו בלי להתקין (10 דקות)

1. מורידים את ה־ISO ואת `SHA256SUMS` מ־[GitHub Releases](https://github.com/diamondrubinny/D.Ai/releases) ובודקים אותם ([INSTALL.md](INSTALL.md)).
2. צורבים לדיסק און קי (Rufus במצב DD, ‏Ventoy או balenaEtcher), ומאתחלים ממנו.
3. בסשן ה"חי" פותחים את D.Ai Command (`Super+Space`) וכותבים: **"will my wifi work?"** או **"האם המדפסת תעבוד?"**. ‏`dai-doctor hardware` בודק Wi-Fi, רשת, גרפיקה, קול, מצלמה, ‏Bluetooth ומדפסת, **לפני** שמשנים משהו במחשב.

## שלב 2: גיבוי מ־Windows (חובה)

- מעתיקים את `C:\Users\<השם שלכם>` לדיסק חיצוני, או לפחות את Documents, ‏Pictures, ‏Desktop ו־Downloads.
- ‏**BitLocker:** אם הכונן מוצפן, ‏D.Ai לא יוכל לקרוא אותו. לכן מעתיקים מתוך Windows, או שומרים את מפתח השחזור של BitLocker.
- רושמים את סיסמאות ה־Wi-Fi החשובות (Windows לא מאפשר להעביר אותן).
- סימניות: ‏D.Ai Move מעביר אותן מ־Chrome ו־Edge. אם אתם משתמשים בסנכרון של Google או Microsoft, אפשר גם פשוט להתחבר בדפדפן.

## שלב 3: התקנה (20–30 דקות)

"התקנת D.Ai OS" משולחן העבודה ← **מחיקת הדיסק** ← סימון **"הצפנת מערכת"** ← יצירת משתמש. פרטים: [INSTALL.md](INSTALL.md).

## שלב 4: היום הראשון

1. **ברוכים הבאים** נפתח לבד: רמת אבטחה, מודלי AI שמתאימים לזיכרון של המחשב, ופרטיות.
2. **מעבירים את הקבצים:** מחברים את הדיסק עם הגיבוי וכותבים ב־D.Ai Command ‏**"תעביר את הקבצים מווינדוס"** ‏(`dai-move`). מוצג סיכום, שום דבר לא נדרס, והסימניות עוברות לקובץ שמייבאים ב־Firefox ([MOVE.md](MOVE.md)).
3. **מתקינים מה שצריך** עם `+`: ‏`+ steam`, ‏`+ zoom`, ‏`+ מדפסת`, ‏`+ install word`, ‏`+ תוכנות ווינדוס`.
4. **מגדירים גיבוי:** ‏**"גבה את הקבצים שלי"** ‏([BACKUP.md](BACKUP.md)).

## מילון קטן: מה זה מה

| ב־Windows | ב־D.Ai OS |
|-----------|-----------|
| כפתור התחל | 💎 היהלום, משמאל למטה (או `Super`) |
| חיפוש ב־Start | ‏`Super+Space` ‏(D.Ai Command): אפליקציות, קבצים ("ה־PDF מאתמול"), חישובים, שאלות |
| הגדרות | כותבים מה רוצים: ‏`!נעל מסך אחרי 5 דקות`, ‏`!חסום דיסק און קי` ‏([TUNE.md](TUNE.md)) |
| Microsoft Store | ‏`+` ב־D.Ai Command ‏(D.Ai Forge), או Flathub |
| Task Manager / "למה איטי?" | ‏**"למה המחשב איטי?"** ‏(D.Ai Doctor) |
| ‏Windows Defender | ‏חומת אש ו־AppArmor פעילים; אנטי וירוס בבקשה: ‏`+ תתקין אנטי וירוס` |
| ‏Win+L | ‏`Super+L` |
| ‏Alt+Shift להחלפת שפה | אותו דבר |
| ‏Copilot / Recall | ‏AI **מקומי**: ‏`?` ב־D.Ai Command. שום דבר לא נשלח ולא מוקלט |

## אם משהו לא עובד

1. ‏**"למה ה־X לא עובד?"** ב־D.Ai Command ‏(D.Ai Doctor).
2. כל שינוי שעשיתם עם Tune או Forge אפשר לבטל: ‏`dai-tune undo`.
3. מדווחים ב־[GitHub Issues](https://github.com/diamondrubinny/D.Ai/issues), עם הפלט של `dai-doctor --json` (בלי פרטים אישיים).
