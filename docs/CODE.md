# D.Ai Code: עוזר קוד מקומי לפרויקט שלכם (v0.1)

> עוזר קוד שעובד על הפרויקט שלכם ויושב בטרמינל. הוא מסביר, מציע שינויים כ־diff לאישור, ואפשר לבטל כל שינוי. ה־AI רץ במחשב, וקוד לא יוצא ממנו.

## 1. פקודות

```bash
cd ~/projects/my-app
dai-code ask "איפה מטפלים בהתחברות משתמשים?"      # תשובה על סמך קבצי הפרויקט הרלוונטיים
dai-code explain src/auth.py                       # הסבר על קובץ
dai-code explain src/auth.py:40-80                 # או על טווח שורות
dai-code edit src/auth.py "הוסף בדיקה שהסיסמה לא ריקה"   # diff לאישור, גיבוי, undo
dai-code review                                    # סקירת השינויים שלא נשמרו ב־git (git diff)
dai-code commit-msg                                # הצעה להודעת commit לשינויים ב־stage
dai-code undo                                      # ביטול השינוי האחרון שהעוזר ביצע
dai-code history
```

אפשרויות: ‎`--yes` (החלה בלי שאלה, ואפשר לבטל עם undo), ‎`--dry-run` (רק להציג את ה־diff), ‎`--root DIR`.

## 2. איך זה עובד

```
שורש הפרויקט (git rev-parse, או התיקייה הנוכחית)
   │  רשימת קבצים: git ls-files, או סריקה שמדלגת על .git, node_modules, venv, build...
   ▼
בחירת הקשר: ציון רלוונטיות לפי מילים מהשאלה, בשם הקובץ ובתוכן; עד ~14K תווים
   │  סודות מוסתרים: ‎.env, מפתחות פרטיים, ‎*.pem, AWS/GitHub tokens → [REDACTED]
   ▼
daid (task="code" → מודל הקוד אם הוא מותקן) — מקומי, AF_UNIX בלבד
   ▼
ask/explain/review → טקסט       edit → JSON {summary, content} → diff מקומי → אישור → גיבוי → כתיבה
```

## 3. אבטחה

| איום | בקרה |
|------|------|
| ה־AI מריץ קוד או פקודות | **אף פעם.** הוא מחזיר טקסט, או תוכן קובץ שמוצג כ־diff ונכתב רק אחרי אישור |
| כתיבה מחוץ לפרויקט | כל נתיב עובר `resolve()` ונבדק שהוא בתוך שורש הפרויקט. symlink שיוצא מהפרויקט נדחה |
| שינוי קבצים רגישים | `.git/`, ‏`.env*`, מפתחות ותעודות נחסמים לעריכה, וגם לא נשלחים למודל |
| דליפת סודות להקשר של המודל | הסתרה לפי דפוסים (private key, AWS, GitHub, Slack, JWT, ‏`password=`) לפני השליחה |
| "הרסתי את הקובץ" | גיבוי לפני כל כתיבה ב־`~/.local/state/dai/code` (0700) ו־`dai-code undo`. הכתיבה אטומית |
| קובץ גדול או בינארי | עריכה מוגבלת לקבצי טקסט UTF‑8 עד 12KB. קבצים בינאריים לא נקראים |
| prompt injection מתוך קוד | ההשפעה מוגבלת להצעה שמוצגת לאישור. אין כלים ואין רשת |

## 4. מגבלות ידועות

- מודל קטן (1.5B) מתאים להסברים ולשינויים נקודתיים בקובץ אחד, ולא לשינויים רחבים בכמה קבצים.
- הקשר מוגבל (כ־8K טוקנים): ב־`ask` נכנסים רק הקבצים הרלוונטיים ביותר.
- אינטגרציה לעורכים (Neovim, VS Code/VSCodium) עדיין לא קיימת ומתוכננת.
