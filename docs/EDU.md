# D.Ai OS Education: מהדורת חינוך וניהול צי מחשבים (v0.1)

> ‏ChromeOS כבשה את בתי הספר בזכות חומרה זולה וניהול מרוכז. ‏HeBuntu, הפצה בעברית לבתי ספר, לא התממשה ([GROWTH.md](GROWTH.md)). ‏D.Ai Education מציעה מערכת בעברית, בלי חשבון ענן ובלי איסוף מידע על תלמידים, שמנהלים ממקום אחד.

## 1. מה במהדורה

| | |
|-|-|
| כל מה שיש במהדורת המשתמשים | ‏LibreOffice בעברית, דפדפן, ‏AI מקומי, הכתבה, ‏Find, ‏Doctor, ‏Backup, מחוון פרטיות |
| אפליקציות למידה | ‏GCompris (גם בעברית), ‏Tux Paint, ‏TuxMath, ‏Stellarium, ‏KGeography, ‏Kalzium, ‏KTurtle, ‏KBruch, ‏KWordQuiz, ‏KLettres, ‏Marble. רק מה שקיים ב־Debian נכלל: הרשימה מסוננת בזמן הבנייה |
| מדיניות ארגונית | `/etc/dai/policy.d/` (בהמשך) |

‏Scratch ו־GeoGebra לא נמצאים ב־Debian. אם צריך, מתקינים מ־Flathub (`+ flathub`).

## 2. מדיניות ארגונית: אותם משפטים, לכל המחשבים

מנהל המערכת (רכז מחשוב, ספק IT) כותב קובץ אחד:

```json
{"format": 1, "name": "מחשבי כיתה", "apply": ["block usb storage", "turn off bluetooth", "lock the screen after 5 minutes", "enable automatic updates", "install gcompris-qt"]}
```

ומעתיק אותו ל־`/etc/dai/policy.d/10-school.json` בכל מחשב, בכל דרך שנוחה: דיסק און קי, Ansible או חבילת deb משלו. המדיניות מוחלת **מיד**, כי `dai-policy.path` עוקב אחרי התיקייה, וגם **בכל אתחול** (`dai-policy.service`). מדיניות שלא השתנתה לא מוחלת שוב.

| בקרה | |
|------|-|
| מי יכול לקבוע מדיניות | רק root: הקובץ חייב להיות בבעלות root, לא ניתן לכתיבה ע"י group/others, לא symlink, ועד 64KB. אחרת הוא נדחה |
| מה מותר | רק פעולות מערכת מהקטלוג הסגור של D.Ai Tune (חסימת התקנים, חומת אש, עדכונים, חבילות, אזור זמן, שם מחשב וכו'). מהגדרות המשתמש, רק **נעילת מסך**: ‏"lock the screen after 5 minutes" הופך למגבלה לכל המשתמשים (§2.1). הגדרות משתמש אחרות נדחות עם הסבר |
| שקיפות | `dai-tune policy` מראה לכל משתמש איזו מדיניות פעילה, מה היא עושה ומה נדחה ולמה. כל החלה נרשמת ביומן המערכת וב־syslog |
| ביטול | כל החלה היא רשומה רגילה ביומן של Tune, ואפשר לבטל אותה. מחיקת קובץ מדיניות **לא** מבטלת אוטומטית את מה שהוחל |
| דוגמה | `/usr/share/dai/policy-examples/school.json` (לא פעילה) |

### 2.1 נעילת מסך לכל המשתמשים

- המדיניות כותבת `/etc/dai/policy-session.env` ‏(`DAI_LOCK_MAX_SECONDS`, בבעלות root, ‏0644). ‏"never lock the screen" במדיניות נדחה.
- בכל כניסה, ה־autostart של labwc **קורא** את הקובץ (לא מריץ אותו) ומגביל את הזמן: משתמש יכול לבחור נעילה מוקדמת יותר, לא מאוחרת יותר ולא "אף פעם". ‏D.Ai Tune מסרב לבקשות כאלה ומסביר למה, ו־`dai-tune status` מראה את הזמן בפועל.
- חל מהכניסה הבאה של כל משתמש.
- **מגבלה:** זו מדיניות נוחות, לא גבול אבטחה. משתמש שיודע מה הוא עושה יכול לעצור את swayidle בסשן שלו או לערוך את `~/.config/labwc/autostart`. משתמשים שנוצרו לפני העדכון מקבלים את ה־autostart החדש רק כשהקובץ שלהם מוחלף (‏`cp /etc/skel/.config/labwc/autostart ~/.config/labwc/`).

## 3. פרטיות תלמידים

- אין חשבון ענן, אין טלמטריה ואין מעקב. ה־AI וההכתבה רצים במחשב.
- מחוון הפרטיות מראה לתלמיד כשמשהו מקליט או מצלם.
- ‏**דורש בדיקה משפטית** לפני פריסה במוסד: חוק הגנת הפרטיות (כולל תיקון 13), חוזרי מנכ"ל של משרד החינוך בנושא אבטחת מידע ופרטיות, ומידע על קטינים.

## 4. נגישות

ראו [ACCESSIBILITY.md](ACCESSIBILITY.md). קורא מסך, ניווט במקלדת, הגדלה וממשק מימין לשמאל. **דורש בדיקה של מורשה נגישות** לפני פריסה במוסד ציבורי.

## 5. מגבלות ומה הלאה

- אין עדיין שרת ניהול מרכזי עם ממשק. ההפצה של קבצי המדיניות היא באחריות המנהל.
- אין עדיין חשבונות תלמידים מנוהלים (LDAP/AD) או "מצב בחינה". **מתוכנן**.
- מדיניות להגדרות משתמש (נעילת מסך, רקע) מתוכננת.
